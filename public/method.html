Project note · neural evolution

I made an arcade game into a small, inspectable experiment in learning.

This is not a pre-trained agent performing a trick. Every bird is a distinct neural network, evaluated on the same course, selected by fitness, and recombined into the next generation in the browser.

01 · decision loop

Each frame is a compact control problem.

I give the network only velocity, the horizontal distance to the next gate, and the distance to each edge of that gap. Its single output is thresholded into a flap. The live lab shows these values and the exact topology for the current fitness leader.

02 · evaluation

Fitness rewards progress, but survival still matters.

All genomes receive the same deterministic pipe sequence. Remaining alive earns a small continuous reward; a clean gate pass earns a much larger bonus; collisions apply a small penalty. Holding the course fixed makes improvement in the first-gate rate meaningful rather than luck from easier pipes.

The gold point is a hypothetical pipe pass. It is intentionally visible in the reward curve because it changes selection pressure.

03 · NEAT

Evolution changes both weights and structure.

NEAT starts with a sparse network. Better genomes reproduce, while compatible structures are grouped into species so new ideas are not immediately eliminated by already-optimized simple policies. Across generations, mutations can adjust a weight, add a connection, or insert a hidden node.

The lab’s Speciation and Structural mutation controls change these exact settings for future offspring: lower compatibility thresholds create more species, while higher structural rates explore architectures more aggressively.
